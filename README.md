## Notes

- 海風ローカル線は架空路線のゲームです。実際の鉄道設備や運転手順を再現・案内するものではありません。
- Focus Flow AI と FOCUS LAB の表示値は実験的な視覚サインであり、集中力や能力を科学的に判定するものではありません。
- PON! LAB は短いラウンドで小さな達成感を楽しむミニゲーム集です。通知、連続ログイン圧力、課金ガチャなどは設けていません。
- `Minecraft-good-seed` リポジトリは確認時点で空だったため、収録対象のソースはありませんでした。
